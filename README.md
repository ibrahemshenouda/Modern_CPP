# Modern C++ Concepts

Welcome to the **Modern C++** repository! This project serves as a comprehensive collection of code snippets, examples, and notes dedicated to exploring modern C++ standards (C++11/14 and beyond) and best practices. It's designed to guide learners through foundational C++ concepts up to building a practical console application.

## 🗂️ Topics Covered

This repository focuses on core concepts structured logically into the following modules under `01_Basics`:

1. **[01_C++_File_Strcture](./01_Basics/01_C++_File_Strcture)** - Understanding the basic structure of a C++ program.
2. **[02_Input_Output_Stream](./01_Basics/02_Input_Output_Stream)** - Standard I/O operations using `std::cin` and `std::cout`.
3. **[03_Hello_user](./01_Basics/03_Hello_user)** - A simple introductory program interacting with the user.
4. **[04_Array](./01_Basics/04_Array)** - Fixed-size array data structures.
5. **[05_String](./01_Basics/05_String)** - Working with C++ standard strings (`std::string`).
6. **[06_New_Container](./01_Basics/06_New_Container)** - Modern C++ standard template library (STL) containers.
7. **[07_Control_Flow](./01_Basics/07_Control_Flow)** - Decision-making structures (if, else, switch).
8. **[08_Loops](./01_Basics/08_Loops)** - Iteration control (for, while, do-while).
9. **[09_Operators](./01_Basics/09_Operators)** - Arithmetic, logical, and relational operators.
10. **[10_Functions](./01_Basics/10_Functions)** - Reusable blocks of code, pass-by-value, and pass-by-reference.
11. **[11_Pointers](./01_Basics/11_Pointers)** - Memory addresses and pointer manipulation.
12. **[12_User_defined_datatypes](./01_Basics/12_User_defined_datatypes)** - Introduction to structs and classes.

## 🚀 Capstone Project

**[13_Project: User Registration Application](./01_Basics/13_Project)**  
A culminating console-based application that applies the concepts learned. It allows users to register personal details (Name and Age) and retrieve them via a unique identifier, demonstrating practical usage of classes, arrays, loops, and control flow.

## 🛠️ Prerequisites

To compile and run the examples in this repository, you will need:
- A C++ compiler (e.g., GCC, Clang, or MSVC) that supports C++11 or newer.

## 🏃‍♂️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ibrahemshenouda/Modern_CPP.git
   cd Modern_CPP/01_Basics/<topic_folder>
   ```
2. Compile the source file using your C++ compiler (e.g., `g++`):
   ```bash
   g++ main.cpp -o main
   ```
3. Run the compiled executable:
   ```bash
   ./main
   ```
